# 高三英语教学工作空间

把一位高三英语老师的日常文档工作固化下来：**在对话里发文件/图片 + 一句话，直接产出 Word**。
不写代码、不装软件、不经过任何中间层。

---

## 四条链路

| 任务 | 输入 | 输出 |
|---|---|---|
| **讲义生成** | 考卷 + 答案 docx（可同文件） | 备课讲义版 docx |
| **作文批改** | 作文题目 + 学生作文（或手写照片） | 批改与升格 docx |
| **试卷识别** | 试卷图片（多张，顺序可乱） | 转录排版后的 docx |
| **链接文档下载** | 小红书等分享链接 | 原文件（默认已去水印） |

另有**附加工序**：PDF 合并 / 转图片 / 抽内嵌图 / Word 转 PDF（`规范/05`）。只换壳、不改内容，
**默认不装任何依赖**，用到才装；LibreOffice 那 806 MB 一律不代装，只给国内镜像地址。

规范在 `规范/`，模板在 `模板/`，示例在 `示例/`。规范已经写死，用户发文件时不需要重复交代格式要求。

最后一条是**前置工序**：从链接里把 Word 掏出来、顺手去水印，再交给前三套继续加工。
它**不用提示词**——发来小红书链接（含微信分享卡片），只要跟 Word 下载或英语试卷相关，就直接开跑。

## 核心规则

**1. 口令只保护「产物规则」**

判断标准只有一条：**这个改动会不会让生成的 Word 长得不一样？**

- **会变** → 属于产物规则（`规范/` 六份 md、`模板/` 两份 docx、`示例/`、`工具/strip_watermark.py`），
  必须用户本人连续说出「修改规则」四个字才能改。agent 自己复述的**不算数**。
- **不会变** → 属于说明文档（README、索引、HANDOVER、技术要点、check.py、xhs_grab.mjs、变更日志），
  直接改，不用口令，但要记日志。

**口令只授权改文件，不授权升版。** 改完记进 `HANDOVER.md` §0.5 待办，不打 tag、不推送。
等用户说「升版 / 推送 / 同步」，才升版本号、打 tag、推送，三件事一起办。

**2. 临时要求优先，但不污染规范**

对话里的临时要求覆盖规范对应条款（比如「这次忽略卷面缺失」）。
但一次性要求**绝不写进 `规范/`**，要固化必须用户明确说「以后都这样」。

**3. 交付只说原材料的问题**

因原材料导致的瑕疵必须提醒：原件本身有错、字迹难以辨认、缺页截断、原件自相矛盾。
**排版执行情况不汇报**（字号、颜色、页边距这些打开就能看到），也不说「一切正常」。

**4. 成品永不备份**

生成的 docx 只在本地，不入 git、不上传。成品含学生作文原文，不适合放线上。

**5. 默认去水印**

从任何渠道拿到的文档，只要有水印就直接清掉再交付，不先给带水印的再问。
页眉、页脚里的图形与 logo 一律视为水印删除；页码保留；正文插图不动；只有吃不准时才问一句。

## 技术要点

- **字体必须显式写四槽**（`w:ascii` / `w:hAnsi` / `w:eastAsia` / `w:hint`）。
  少了 `w:hint="eastAsia"`，圈号 ①②③ 和全角标点会掉进 Times New Roman，跟旁边的宋体不是一套。
- **运行环境固定**：本机 macOS + 中文版 Word。不考虑 WPS、旧版 Word、Windows、跨平台。
- **模板只作版式参照**，字体不能照抄——模板靠主题继承，`python-docx` 新建文档的默认主题是 Calibri。
- 成品交付前跑 `工具/check.py` 体检。
- **依赖一律走 `./工具/py`**（首次自建 `.venv`，走国内镜像，约 10 秒），不要裸敲 `python3`；
  也不往系统 Python 里装东西，不用 sudo。

## 打包与安装技能包

**不需要任何外部提示词文件**：判据写在 `AGENTS.md` 文末《两个自服务动作》。

- **打包**：把仓库名（或链接）丢给任意 agent，说一句「打包成技能包」——甚至不用说，它读到 `AGENTS.md` 就知道。
  它会现场探测 tag 与未提交改动，只装规则 / 模板 / 脚本 / 硬知识 / 硬规矩五类，产出
  `<用户文档目录>/技能包-<仓库名>-<日期>.zip`——用户文档目录按平台取（macOS `~/Documents`、
  Windows `%USERPROFILE%\Documents`、Linux `$XDG_DOCUMENTS_DIR`），打完 zip 不留中间目录。
  **技能包不进 `生成物/`**——那是给 Word 成品的，技能包是仓库自述。
- **安装**：把 zip 直接丢进对话，说「安装」——或者什么都不说也行，agent 认得出根目录的 `SKILL.md` + frontmatter，
  会装到 `~/.workbuddy-ai/skills/<name>/` 并回一句触发词。

包里必带「首次安装」一节（探测 `python-docx` / `pymupdf` / `soffice` / node / chromium，缺什么补什么；
LibreOffice 只提示不代装），否则换台机器第一步就卡住。

## 版本

当前 `v1.25`。**改规则和升版是两件事**：口令只改本地文件，用户说升版才打 tag 推送。

每个版本对应一个 GitHub Release，源码 zip 不需要登录就能下：

```bash
# 固定版本
curl -LO https://github.com/xitihangto/english-teacher-workspace/archive/refs/tags/v1.25.zip
# 永远最新
curl -LO https://github.com/xitihangto/english-teacher-workspace/archive/refs/heads/main.zip
```

包内只有版本库里的规则、模板和脚本，**不含 `生成物/` 与 `原料/`**。这两个地址都会 302 跳到
`codeload.github.com`，套反向代理时两个域名都要覆盖。

Release 由 CI 自动建（`.github/workflows/release.yml`），说明取自 `变更日志.md` 的版本条目——升版时不用手建。

回归某一版：

```bash
git checkout v1.0 -- .
```

改动前先读 `变更日志.md`。
