# 图片转 Word 文档（Python 脚本）提取与排版规则

## 一、 运行环境与输出要求
- **依赖库**：仅限使用 Python 自带的库以及 `python-docx` —— **用户的环境只有 Python 3.12.15 和 python-docx**，没有其他第三方库。
- **输出形式**：直接提供完整可执行的 Python 代码，无需生成实际文件。
- **执行结果**：代码运行后，需在工作区的 `生成物/` 子目录下自动生成完整的 Word（`.docx`）文档；输入图片等原料放 `原料/`，不放根目录。

## 二、 图像与内容处理规则
- **去噪**：必须忽略图片中无用的部分，如：水印、手机/平板软件的操作界面（如顶部状态栏、返回按钮、小红书号等）。
- **排序与拼接**：图片顺序可能混乱。**首要排序依据是卷面的大标题结构（如：罗马数字 I, II, III；中文数字 一、二、三；或阿拉伯数字 1. 2. 3. 等）**，辅以上下文语义理解，智能整理出正确的逻辑顺序（如：听力 -> 语法 -> 阅读 -> 写作）。
- **去重与补全**：识别图片间的重叠部分，避免在 Word 内重复输出；对于缺失的极小部分（断页导致的解析部分缺失不受下方**绝对保真**规则的约束），需利用语义智能补齐 —— **补的是解析还是本体，界限见下方两条「残缺处理」，以那两条为准**。
- **【最高优先级】绝对保真**：**严禁自作主张删除图片内的任何文字内容（操作界面文字和明显是截图时重复的部分不受此规则限制）**。必须逐字逐句完整提取，包括所有的解析、冗长的文本、甚至两个版本的范文答案。不得为了排版清爽而概括或省略任何细节。
  - **逐字转录，不做校对**：只要原图文字清晰，就照原样录入。**不要修正任何错别字**（原文写错的字、用错的标点、明显的笔误，一律照抄），**不要调整语序**，**不要重排题目或选项**（原题号是 3、4、5 就写 3、4、5，不要改成 1、2、3；A/B/C/D 选项的顺序也照原样，不要按内容重新排）。
- **残缺处理之一：解析部分允许智能补全**。拼接错位或图片特别模糊，导致某段文字只能看见半行、字体被截断时，先判断它属于哪一部分：
  - 属于**试卷本体**（题干、选项、原文、听力材料、作文要求等）→ **不许猜**，按下面「缺页占位」那条处理。
  - 属于**解析、答案、范文**这类参考性内容 → 允许依据上下文语义**补全成通顺完整的一两句话**，不必保留截断的痕迹，也不必标注哪里补过。
- **残缺处理之二：缺页用标记占位**。试卷可能不完整 —— 开头少几页、中间断了几页、或者结尾缺页。凡是能判断出「这里本该还有内容、但图里没有」的位置，**不要凭想象补写正文**，而是插入一个占位标记：

  - **文字**：`此处可能缺页`（六个字，不要加别的说明）
  - **字体**：**蓝色**（`#0000FF`），**三号**（16pt）
  - **实现方式**：和下面的「插图占位」一样，用 **1 行 1 列表格**模拟文本框，但边框必须是**黑色单线**（`python-docx` 默认表格无边框，需显式加 `single`、8 号、黑色）。
  - **宽度**：页面去掉左右页边距后可用宽度的 **80% 左右**。按本文档页边距 2.2cm、A4 宽 21cm 算，可用宽度 16.6cm，即**约 13.3cm**。写进 XML 时 `w:tblW` / `w:gridCol` 用 **twips = cm × 567**（1 cm = 567 twips）——**不要写成 cm ÷ 2.54 × 567**，那是英寸换算，表会只剩一半宽、单元格假换行、整表纵向拉长。另把 `w:tblInd` 显式写 0，边框才和正文页边距对齐。
  - **高度**：**不要写死**。用段落间距实现「框内文字上下各留一行高」——即该段落的段前、段后间距各设为约一个字高（三号 16pt 约 18pt），表格高度由内容自动撑开。**不要用 `trHeight exact`**（那是插图占位框的写法，这里是自动高度）。
  - **位置**：表格在页面水平居中。
  - **判断依据**：页码跳号、大题编号断开（如从「二」直接跳到「四」）、上下句明显接不上、图片边缘出现半截题号或半行字、某道题的选项只出现 A、B 就断了等。
- **插图处理（默认保留，无需询问）**：
  - **本体系默认保留图文**，直接把图处理进成品即可，**不必为此向用户确认**。这一点与「讲义生成」相反——讲义默认移除且必须先问，原因见 `规范/01-讲义制作规则.md` §0。
  - **首选：把原图裁出来插进 Word**。原件含插图（图表、示意图、漫画、表格截图等）时，用 `page.get_pixmap(clip=...)` 或图片裁剪的方式，把该插图单独截出，用 `add_picture` 插到**原文对应的段落位置**，宽度按版心自适应（不超过 14cm）。
  - **位置还原到什么程度**：按**段落顺序**对上即可。文字环绕、跨栏、多图并排这类排版**不要求还原**，也不应为此耗时——做不到是正常的，强行对齐反而更乱。
  - **退路：确实拿不到原图时，才用占位框**。因输入只有文字（如链接里图没抓到）或图已被裁断无法复原时，采用「1 行 1 列表格」模拟插图框：列宽 14cm、行高按原图大致高宽比用 `trHeight exact` 锁定，表格居中，框内文字水平垂直居中，字体固定紫色 **`#800080`**，内容格式为"此处原为插图：插图内容为……"，**最多 30 个中文字**。
  - **插图特别不清晰时**（糊、暗、被遮挡、分辨率过低）：仍按最可能的读法处理，但**必须在交付文字里点一句**，说明这处不可靠，不要默默放过。
- **输出形式要先问**：输入明显可能导致成品超过单篇时（如一次给了两三份试卷），**必须先问用户要合成一份还是分开出**，不得自行决定。

## 三、 字体与样式规则
- **中文字体**：一律使用 **宋体**（包括全角符号，如圈码数字等）。
  - **必须显式设 `w:hint="eastAsia"`，否则上面那句等于没写**。Word 里 `w:rFonts` 有四个槽：`w:ascii`（基本拉丁）、`w:hAnsi`（拉丁扩展）、`w:eastAsia`（东亚）、`w:hint`（**既不算纯西文也不算纯东亚的「歧义宽度」字符按哪个槽取字体**）。圈码 ①②③、全角标点（，。：；！？（）「」《》、——……）、全角空格都属于歧义宽度字符，**`w:hint` 不是 `eastAsia` 时它们按 `w:ascii` 走，也就是 Times New Roman**。
  - `python-docx` 的 `run.font.name` **只写 `w:ascii` / `w:hAnsi`，根本不碰 `w:eastAsia` 和 `w:hint`**，所以「中文宋体 + 英文 Times New Roman」这套写法对圈码天然无效，必须自己补全四个槽：
    ```python
    from docx.oxml.ns import qn
    rF = run._element.get_or_add_rPr().get_or_add_rFonts()
    rF.set(qn('w:ascii'), 'Times New Roman')
    rF.set(qn('w:hAnsi'), 'Times New Roman')
    rF.set(qn('w:eastAsia'), '宋体')
    rF.set(qn('w:hint'), 'eastAsia')      # ← 少了这一行，①②③ 和全角标点就变西文
    ```
  - 设了 hint 之后，同一个 run 里的纯英文单词和数字照样走 Times New Roman，只有圈码和全角标点改用宋体 —— 正是想要的效果。
- **英/数字体**：一律使用 **Times New Roman**。
- **字重与颜色**：是否加粗需根据图片原版样式尽量保持一致；原图中的红色解析、答案文字一律用 **`#C00000`**（Word 标准色里的「深红色」，即纯红往左一格）——**不要用纯红 `#FF0000`**，纯度太高，满屏看着刺眼；插图占位描述文字强制为紫色（`#800080`）。
- **字号（硬性，只有三档）**：
  - **默认五号 = 10.5pt**。本规则没有单独规定字号的地方，一律 10.5pt —— 包括正文、题干、选项、解析、答案、`I. Grammar and vocabulary` / `Section A` 这类小标题、插图占位框里的紫色说明文字。
  - **卷头大标题**（试卷最上面那一两行，如「2026-2027学年…评估英语卷」「(解析版)」）：**四号 = 14pt，加粗**，中文宋体、英文 Times New Roman。
  - **缺页占位框**里的「此处可能缺页」：**三号 = 16pt**（见上文残缺处理之二，不随本条缩小）。
- **首行缩进（硬性）**：原文有明显段首缩进时（如英文文章每段开头空两格），**用段落属性设置首行缩进 2 字符**，**绝对不要在文字前面手工敲空格**（半角、全角、Tab 一个都不许加）。
  - **实现方式**：优先用 Word 的字符单位 —— 底层 XML 里给 `w:ind` 设 `w:firstLineChars="200"`（200 = 2 字符）。用 `python-docx` 时直接改 `paragraph._p.get_or_add_pPr()` 下的 `ind` 元素即可。
  - 退一步的等价写法：`paragraph_format.first_line_indent = Pt(21)`（五号 10.5pt × 2 = 21pt）。字号不是 10.5pt 的段落不要用这个，会缩错宽度。
  - 整篇文档的缩进必须完全一致，不许有的段缩进、有的段不缩。

## 四、 排版与版面规则
- **整体版式**：尽量接近原图，但无需 100% 完美复刻排版边距。
- **试卷专用元素**：**绝对保留**原版中的填空、括号选项、表格结构等试卷专用内容。
  - **填空一律用下划线模拟待填处**：每个空处的横线**固定 6 个半角下划线**（`______`），不多不少，不许写 3 个、8 个或更多。
  - **编号符号放在横线的哪个位置，完全忠于原图**，三种排法：
    - **居中** → `___1___`（3 个下划线 + 编号 + 3 个下划线）
    - **靠左** → `1______`（编号 + 6 个下划线）
    - **靠右** → `______1`（6 个下划线 + 编号）
  - **编号可以是**：阿拉伯数字（1、2、3…）、大写字母（A、B、C…）、小写字母（a、b、c…）、带括号的数字（（1）、(1)）、圈码数字（①②③④⑤⑥⑦⑧⑨⑩⑪⑫⑬⑭⑮⑯⑰⑱⑲⑳）。**原图用什么就用什么，不要统一改写成某一种，也不要自己发明格式。**
  - **下划线两边不能有空格**（绝对不要写成 `___ 1 ___`，也不要在横线前后加空格去凑对齐）。
- **空行控制**：
  - **大题之间**：必须有明显的空行分隔。
  - **题目内部**：尽量不设空行，保持紧凑（空行的定义：一个回车符或换行符单独占一整行，不可滥用）。

## 五、 页面设置规则（硬性规定）
- **页边距**：强制设置 Word 的上、下、左、右页边距各为 **2.2 cm**。
- **装订线**：强制设置装订线为 **0 cm**。
